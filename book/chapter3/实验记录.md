## 一、实验 3-2：书籍原始设计

### 1.1 实验目标与要求

实验目标是在统一条件下比较 Simple Notes、Enhanced Notes、JSON Cards、Advanced JSON Cards 四种记忆格式的记忆生成、更新、检索和最终回答表现。

书籍明确要求：
1. 四种模式提供统一的记忆生成、更新和检索接口。
2. 使用实验 3-1 同一组 60 个用例。
3. 比较四种格式的最终回答表现。

### 1.2 数据集与执行约束

- 共 60 个 YAML 用例，三个层次各 20 个。
- 第一层以单会话明确事实为主；第二、三层涉及跨时间、跨对象和多段会话。
- 按会话顺序生成和更新记忆。
- 后续会话处理只能访问已有记忆和新会话，不能回看之前的原始会话。
- 所有会话处理完成后，根据最终记忆和新问题生成回答。
- 使用独立评审模型（LLM-as-a-judge）对照参考答案和评分要求进行评价。
- **答题模型不能直接访问原始历史会话或评审材料**，避免将答案或评审信息泄漏给答题模型。

### 1.3 书籍报告结果

| 格式 | 通过用例数 |
|---|---:|
| Simple Notes | 48 |
| Enhanced Notes | 52 |
| JSON Cards | 51 |
| Advanced JSON Cards | 49 |

书中还报告了不同格式的 Token 消耗和模型调用耗时差异。以上均为书籍报告结果，不是本项目实验结果，也不作为本项目学习验收指标。

## 三、各格式的实验结论

### 3.1 Simple Notes

- 以独立事实保存记忆。
- 基础 CRUD、JSON 持久化、上下文输出和关键词检索完成人工验证。
- 当前检索为大小写不敏感子字符串匹配，不是语义检索。
- 自动化测试套件未据此认定通过。

### 3.2 Enhanced Notes

- 以自然语言段落保留事实关联。
- 静态表达对比、单样例 LLM 生成、持久化重载和关键词检索边界完成人工验证。
- 单样例使用模型：`qwen3.5:4b`。
- 记录过 5 条独立事实与 1 段 94 字符自然语言记忆的对比；6 个原文关键词命中，5 个语义相近但不含原文关键词的问题未命中。
- 当前检索不是语义检索。

### 3.3 JSON Cards

- 以 `category → subcategory → key` 组织记忆。
- 基础 CRUD、持久化重载和单样例 LLM 生成写入已完成。
- 单样例生成脚本：`book/chapter3/user_memory/step8_json_card_generation.py`。
- 该次生成使用 `qwen3.5:4b`，输出偏好“回答涉及数值时附带单位”，测试文件为 `book/chapter3/user_memory/data/json_cards_llm_test.json`。
- 期间修正过路径遍历错误和测试顺序问题。
- 偏好使用验证：加载 3 张相似卡片，`search_memories("单位")` 命中；月地距离回答包含 384,400 公里和 236,000 英里；光合作用无关问题未机械套用偏好。
- 以上为少量人工验证，不代表自动化测试或整体检索准确率通过。当前检索为类别、子类别、键和值的子字符串匹配；`get_context_string()` 返回全部卡片，不具备语义检索。

## 五、转账更正案例

- 用例文件：`book/chapter3/user_memory/test_cases/layer2/12_contradictory_financial_instructions.yaml`。
- 案例过程：Patricia 最初要求转账 85,000 美元，日期为 10 月 1 日；James 将金额和日期改为 100,000 美元、9 月 27 日；Patricia 随后更正为 95,000 美元、10 月 1 日；最终参考号为 `WT-89089`。
- 已完成理论分析，未运行模型。
- 结论：若基础 JSON Cards 直接覆盖旧值且不保留历史，仅凭最终值无法可靠还原修改过程。

## 六、已确认的设计边界与未验证事项

- 用户经历变化时，旧经历不能继续作为当前事实；应保留历史并明确当前状态。该设计要求已确认，但尚未在当前数据模型和管理器中实现。
- `backstory` 只能记录来源支持的背景，不能编造人物动机、修改原因或事实时间。
- `person` 表示事实主体，`relationship` 表示主体与用户的关系。
- 创建时间、事实有效时间和事实变化时间不能混为一谈。
- Advanced JSON Cards 不等于完整历史版本审计，也不能替代原始对话证据。
- 同一业务对象的属性变化不应自动改变对象身份；具体标识算法尚未确定。
- Advanced JSON Cards 尚无代码和实验验证；上述字段理解及设计边界不能描述为当前项目能力或书籍规定的固定字段。
- 自动化测试套件尚未据此认定通过。
